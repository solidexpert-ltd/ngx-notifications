# @solidexpert/ngx-notifications

Angular toast library published as `@solidexpert/ngx-notifications`. Applications import `NgxNotificationsModule.forRoot()` and render `<ngx-notifications-list>`.

Original project: [stanvanheumen/ngx-notifications](https://github.com/stanvanheumen/ngx-notifications). Maintained by [solidexpert-ltd](https://github.com/solidexpert-ltd).
